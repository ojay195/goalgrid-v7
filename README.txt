GOALGRID V7 PWA HOSTING PACKAGE

Upload the CONTENTS of this folder to the root of the public GitHub repository named goalgrid-v7.
Keep the folder structure: icons/icon-192.png and icons/icon-512.png.
Then enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).

This is a web-app shell around the existing GoalGrid V7 HTML interface. It does not change or retune the V7 prediction engine. The interface still requires the V7 prediction CSV and (optionally) the eligibility CSV to be imported using its Import CSV button. The app shell can be cached, but imported CSV data is not guaranteed to persist after the browser/app is closed; import the reports again when needed.
